# Folio for MarginNote

![Folio icon](assets/icon-a-44.png)

[下载最新安装包](https://github.com/cheemskc/marginnote-folio/releases/latest)

MarginNote 4 原生文献管理面板。当前版本 0.10.10；入口是学习界面的 Folio 工具栏按钮。安装包运行时不含网页、React 或 WebView。

## 使用

1. 在 MarginNote 资料库创建或选择一个文件夹，打开面板后点顶部「设置」，在独立设置页的「文献库范围」点「更换文件夹」，直接在设置页内选择根文件夹。文献库只读取这个文件夹及子文件夹中的文档；左栏用文件夹图标、展开箭头和数量显示层级，点击箭头展开或收起。宽窗口可以拖动左栏右边界调整宽度。「收起目录」与「收起详情」可分别隐藏左右边栏。选择「全部文献」可恢复整个库。
2. 白色搜索框右侧有「筛选」和「排序」。菜单与按钮等宽，并出现在按钮下方。筛选可同时选择多个文献类型与“仅显示收藏”；排序支持年份、标题、作者、来源、JCR 分区、影响因子。缺少相应数据的文献始终排在最后。
3. 条目左边按文献类型显示期刊论文、学位论文、专利、会议论文、图书、报告、预印本等不同图标。优先使用条目的「文献类型」字段；没有该字段时，只识别标题中明确写出的专利、学位论文，其余显示通用文档图标。标题只显示一行，后面显示期刊标签；下面是作者、年份与来源。右侧用星标收藏，也可打开文献。
4. 右栏有「文献信息」「参考文献与引文」。文献信息顶部展示期刊、年份和标题，下方不重复这三个字段；编辑入口固定在右栏底部。在「文献信息」点「识别并补全文献信息」，插件先用 DOI 查询 Crossref，再尝试按完整标题核对 Crossref / OpenAlex；成功后将规范显示标题、作者、年份、期刊、DOI、摘要、引用数、文献类型、数据来源和获取时间保存到原生元数据文件。摘要按 DOI 依次补查 Europe PMC 与 OpenAlex；Crossref、Europe PMC 均可能没有收录摘要，仍没有结果时会保留空值并显示原因。MarginNote 原文档标题不会被改写。未核对成功不会写入。已有手工字段默认保留。在设置页点「补全当前文献库」可逐篇检查所选根文件夹中的空白书目字段、摘要和期刊指标；已有 Crossref 来源的条目仍会继续补空白摘要或分区，并显示进度；也可开启「打开文献库时自动补全」。资料来源开关只控制查询渠道，不会单独触发查询。
   摘要在作者下方展示，缺失时可点「获取摘要」。手动补全时，如果 Crossref 没有摘要，会按同一 DOI 尝试 OpenAlex，并保存摘要来源；仅获取摘要不会改写标题和作者。数据源没有提供摘要时可手动填写。

右栏编辑使用深色文字、白色输入框和明确边框；「保存」「取消」固定在右栏顶部，滚动长表单时仍可操作。编辑草稿在面板调整大小时保留。
5. 在「文献信息」点「获取期刊标签」，按完整期刊名联网查询并保存。获取只在点击按钮后运行；若在设置中启用“打开详情时自动识别”，只对未有来源记录的文献按需查询。
6. 顶部「定位当前」找到 MarginNote 阅读器正在阅读的文档，在当前文献库范围内切换到该文档所属文件夹、清除搜索与筛选、滚动到条目并显示详情。若文档不在设置中选择的根文件夹内，会给出提示；根文件夹不自动更换。

「参考文献与引文」分别显示本文引用的文献和引用本文的文献。点击各自的「获取列表」按 DOI 或已识别的 OpenAlex ID 查询，每次加载 25 条，支持加载更多及打开 DOI / OpenAlex 来源页面。引用条目采用紧凑三行布局，标题和作者各占一行，年份及来源与右下角的「打开来源」共用一行。列表记录保存在本机 `relations-v1.json`，重新打开不自动联网；修改 DOI 后不会继续显示旧文献的列表。查询使用设置中的 OpenAlex 开关和密钥，429 时暂停该列表查询并保留已下载内容。列表数量以 OpenAlex 收录范围为准，未获取、查询失败和真实空列表分别提示。

文件名采用「年份_标题_作者」时，识别会提取标题、年份与作者线索。截断标题只在长标题前缀、年份、作者均可核对且返回结果唯一时自动保存。批量进度区区分未匹配与请求/保存错误，并显示最近原因；点击停止立即结束任务，迟到响应不会保存资料，也不会继续查询下一来源或文献。

期刊数据优先查询 easyScholar 的 JCR 分区、中科院分区与 JCR IF；需用户自己配置 easyScholar SecretKey。easyScholar 返回官方分区及 customRank 自定义分区标签（包括新锐、CCF、CSSCI 等字段），数据缺失或请求失败时可使用 OpenAlex 同名期刊的“两年平均被引率”。OpenAlex 只提供引用指标，不提供中科院 / JCR 分区，因此不能用它补出分区。遇到 429 或 easyScholar 频率限制时，批量任务暂停，避免继续请求加重限流。该指标单独标示，不作为 JCR IF，也不臆造 IF 年份。两者都没有可靠结果时会显示原因，已有数据不会被清空。OpenAlex 可不填密钥进行轻量查询；高频使用时可配置其 API key。查询有限速、并发去重与期刊名精确匹配。

元数据和数据源设置由原生插件保存到 `Application.sharedInstance().documentPath/com.azeedel.marginnote.paper-library/`。文献数据设置保存在 `paper-data-settings-v1.json`，密钥写入本机 `journal-settings-v1.json`，不在面板回显已保存值，也不进入安装包。已有 `metadata-v1.json` 和根目录设置继续使用，旧版个人评分字段保存在数据文件中以兼容历史数据，但新版界面不再显示个人星级。以后信息获取插件可写入同一结构的期刊字段。

## 构建与安装

```sh
npm run check
npm test
npm run build
```

安装包：`build/marginnote-folio-v0.10.10.mnaddon`。它只含原生脚本、图标和 manifest。`web/`、`legacy-web/` 是旧版参考源码，不参与安装。

## 验证与限制

自动测试覆盖链接文件夹选择、嵌套文件夹、多选筛选与排序、类型图标、DOI/标题匹配、元数据合并、期刊数据解析和保存、请求失败、联网限速、延迟读取及编辑草稿。自动测试无法验证真实 MarginNote 的 UIKit 绘制和文档打开；安装后仍需在宿主中测试。文档若没有关联学习集，公开的打开接口无法直接打开，会提示先加入学习集。MarginNote 文档逐页文本的结构目前不稳定，故不会扫描 PDF 正文查 DOI；本版使用已填写的 DOI、文档标题及文件名中明确出现的 DOI。

原生接口遵循 [MarginNote SDK](https://github.com/marginnoteapp/Addon) 和 [MarginNote 插件文档](https://mn-docs.museday.top/)；文献数据查询使用 [Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) 和 [OpenAlex Works API](https://docs.openalex.org/api-entities/works)；期刊字段遵循 [easyScholar 官方开放接口文档](https://www.easyscholar.cc/open) 与 [OpenAlex Sources API](https://help.openalex.org/api/)。
